# Spec: Multi-Agent Review — client

Spec ID: SPEC-05
Status: implemented
Overview: [../../../docs/specs/multi-agent-review.md](../../../docs/specs/multi-agent-review.md)

## Scope in this module

The studio adds three surfaces: the agent-picker popover on the PR page, the Configure run screen, and the results page with its Columns and Tabs modes and the "Where agents disagree" section. It also adds the index of past multi-agent runs and a GLOBAL sidebar entry. It holds copy 2 of the changed `@devdigest/shared` contracts. It relies on the server for the `agentIds` trigger, the parent list and detail reads, the estimates, the finding actions and the per-run live event stream.

- Copy goes through `useTranslations`. The existing `runs` namespace already holds the conflicts, columns and page copy, whose `page.meta` string no longer mentions p-queue (AC-121) — `../../AGENTS.md:25`, `../../messages/en/runs.json:122`.
- Components call the API only through hooks in `src/lib/hooks` — `../../AGENTS.md:26`.
- Both themes are required — `../../AGENTS.md:29`.
- `src/vendor/ui/**`: extend it with new files; do not rewrite existing components without a reason. The sidebar groups live in `nav.ts` there, and the active key already maps `/multi-agent` — `../../AGENTS.md:36`, `../../src/vendor/ui/nav.ts:25`, `../../src/components/app-shell/helpers.ts:28`.
- The sidebar renders section headers and nav labels as literals from `nav.ts`; `messages/en` `nav.*` feeds only the command palette. NFR-8 therefore exempts exactly the "GLOBAL" header and the "Multi-Agent Review" label (AC-119); every other new string comes from `messages/en` — `../insights.md:53`, `../../src/vendor/ui/nav.ts:25`.
- The live log reuses the per-run event stream, which replays its buffer to late subscribers — `../../../server/src/platform/sse.ts:63`. A column opens its stream only while its run is `running`, and the trace drawer reads the column's stream through its `stream` prop instead of opening a second one (NFR-7) — `../../src/app/multi-agent-review/_components/MultiAgentResultsView/_components/AgentColumn/AgentColumn.tsx:55`, `../../src/components/run-trace-drawer/RunTraceDrawer.tsx:33`.
- The 6-agent cap is a studio rule: `MAX_AGENTS_PER_RUN` caps the pre-selection, "Select all" and manual checking, and the API rejects more than 6 ids (AC-17) — `../../src/lib/multi-agent.ts:7`.
