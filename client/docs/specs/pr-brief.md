# Spec: PR Brief — client

Spec ID: SPEC-03
Status: implemented
Overview: [../../../docs/specs/pr-brief.md](../../../docs/specs/pr-brief.md)

## Scope in this module

The studio owns the client copy of the brief contract and the PR Brief section on the PR Overview tab. That covers the Generate and refresh controls, the header (summary, the newest review's verdict and score, the brief's cost, generation time, stale badge), the missing-data list, Risk areas inside the Intent card, the Review focus list, and navigation from a focus item to a file on the Files changed tab. It relies on the server for `GET /pulls/:id/brief` and `POST /pulls/:id/brief`, and on the existing review data for the verdict and score.
