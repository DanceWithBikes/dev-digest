## Stack
- Node ≥22 · pnpm ≥10 · TypeScript 5.7 · Zod 3.24 · Vitest 2.1
- server: Fastify 5.2 · Drizzle ORM 0.38 · Postgres + pgvector (Docker, :5432)
- client: Next.js 15.1 (App Router) · React 19 · TanStack Query 5 · next-intl
- e2e: agent-browser (CLI, not Playwright)

## Commands
```sh
./scripts/dev.sh              # Postgres → .env → install → migrate → seed → API :3001 + web :3000
cd <package> && pnpm test     # package tests (e2e: npm run e2e:hermetic)
cd <package> && pnpm typecheck
```

## Map
- `server/` — Fastify API, DB, review runs
- `client/` — Next.js UI ("the studio")
- `reviewer-core/` — review engine, no I/O
- `e2e/` — deterministic browser flows
- `docs/agent-prompts/` — system prompts of the built-in agents
- `.claude/skills/` — stack skills (drizzle, fastify, zod, next, react…)

Every package and module has its own `AGENTS.md`, `docs/specs/`, `docs/insights.md`.

## Rules you can't infer from the code
- Agent memory lives in `AGENTS.md`; every `CLAUDE.md` is a committed symlink to its sibling `AGENTS.md` — edit `AGENTS.md`. New module: create `AGENTS.md`, then `ln -s AGENTS.md CLAUDE.md`.
- No workspace: each package has its own lockfile; cross-package imports only via tsconfig `paths`.
- `@devdigest/shared` exists in TWO copies (`server/src/vendor/shared`, `client/src/vendor/shared`) — change both.
- Migrations do NOT run on server boot (`cd server && pnpm db:migrate`).
- API keys live only in `~/.devdigest/secrets.json` or `.env` — never in git or the DB.
- Found something non-obvious (dead end, quirk, recurring error, implicit convention)? Use the `engineering-insights` skill → nearest `docs/insights.md`.

## Do-not-touch
- `server/src/db/migrations/**` — generated by `pnpm db:generate` only.
- `docker compose down -v` — wipes the volume with every imported repo; use `e2e:hermetic` for clean runs.
