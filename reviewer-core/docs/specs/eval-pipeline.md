Spec ID: SPEC-04
Status: implemented
Overview: [../../../docs/specs/eval-pipeline.md](../../../docs/specs/eval-pipeline.md)

## Scope in this module

The engine contributes two pure pieces. The first is the unified-diff parser, moved here from the server so the `eval` module can parse case diffs without importing an adapter, plus a helper that rebuilds a one-file diff from a path and a stored patch. The second is the scoring: the match rule, the case scorer and the micro-averaged batch scorer. Scoring makes no model call and no I/O. The server's batch runner calls the existing `reviewPullRequest` once per case and hands its kept and dropped findings to these scorers.

## Module notes

- No I/O: the only external call goes through the injected `LLMProvider`, and contracts come from `@devdigest/shared`: `reviewer-core/AGENTS.md:19`, `:26`. The scorers import only types from it (the verify guard, AC-120, greps for this).
- The engine's purity is enforced by the server's `arch:check`, and only for files the server's import graph reaches. Export the parser and the scorers from `src/index.ts` and reach them from the server, or they go unchecked: `reviewer-core/docs/insights.md:21`.
- A public API change can break the server typecheck. Check both packages: `reviewer-core/AGENTS.md:25`.
- Citation accuracy inherits the grounding gate's limit: it compares line ranges only, so any line of a brand-new file passes (`reviewer-core/docs/insights.md:47`). This is a Non-goal of SPEC-04.
