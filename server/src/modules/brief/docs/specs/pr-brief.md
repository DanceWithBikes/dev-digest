# Spec: PR Brief — server/modules/brief

Spec ID: SPEC-03
Status: implemented
Overview: [../../../../../../docs/specs/pr-brief.md](../../../../../../docs/specs/pr-brief.md)

## Scope in this module

The brief module serves `GET /pulls/:id/brief` and `POST /pulls/:id/brief`. To generate a brief, it reads the stored intent, the blast radius map, Project Context attachments and the PR's files. It makes one structured model call, grounds the output against the allowed paths, and caches the result per PR. It relies on the server copy of the `PrBrief` contract (AC-1 to AC-8, held by the server package part) and on the container for the blast map, the feature model and document reads.

## Module notes

- A module never imports another module's folder. Intent, the blast map and attachments must arrive through the container, ports or this module's own repository: `server/src/modules/AGENTS.md:17`, `server/src/modules/brief/AGENTS.md:9-10`.
- Business failures (404, 409, 429, generation errors) throw a class from the platform errors file, never a hand-set status: `server/src/modules/AGENTS.md:20`.
- Exactly one structured call per generation, and the adapter's re-ask stays (AC-12, NFR-3); the gate lives in `gate.ts` and the document read has a 15 s sub-deadline: `server/src/modules/brief/AGENTS.md:11`.
- The 90 s deadline runs from request start, a late result must not be stored, and a save already under way is awaited (AC-47): `server/src/modules/brief/AGENTS.md:12`.
- The 5-per-minute limit is per workspace across all PRs and is checked before the in-flight flag (AC-48, AC-49): `server/src/modules/brief/AGENTS.md:13`.
- `pr_brief` has no `workspace_id`, so workspace scoping goes through the PR lookup (AC-11). A stored body that fails contract parsing reads as null (overview OQ-6): `server/src/modules/brief/AGENTS.md:14`.
- One log line per generation, never with body, patch, document or error text (AC-44, NFR-9): `server/src/modules/brief/AGENTS.md:15`.

## Documented deviations

- AC-32: a template, so one withheld patch reads "diff truncated (1 file)": `server/src/modules/brief/constants.ts:34`; test: `server/test/brief-helpers.test.ts:259`.
- AC-31 / AC-32: patches stop at the first one that would cross 60,000 characters and every later one is withheld, even a small one that would fit. Only patches that existed count toward N: `server/src/modules/brief/helpers.ts:115-138`.

Reading documents has a 15 s sub-deadline whose loss reads as "not found" for every document: `server/src/modules/brief/constants.ts:6`, `server/src/modules/brief/service.ts:151-166`.
- AC-49: per workspace across all PRs; rejected POSTs count too; checked before the in-flight flag: `server/src/modules/brief/gate.ts:10-22`.
- AC-24: two agents with the same name are ordered by creation time, then skills of equal link order by id: `server/src/modules/brief/helpers.ts:61`, `:72` (overview OQ-3).
- AC-31 "the PR's file order": `pr_files` has no position column and the read has no `ORDER BY`, so the order is not deterministic: `server/src/modules/brief/repository.ts:33-42`. Fixing it needs a migration outside SPEC-03.
